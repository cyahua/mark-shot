# 鼠标光标与交互状态

光标根据指针下方的操作区域和当前交互状态变化。控件禁用时使用箭头；背景任务只影响所属窗口，不覆盖其他窗口的光标。

| 操作区域 | 悬停状态 | 按住或执行时 | 结束后 |
| --- | --- | --- | --- |
| 按钮、开关、下拉入口 | 手型 | 保持手型 | 禁用时恢复箭头 |
| 标签页、设置分类 | 可用项目显示手型，空白和禁用项目显示箭头 | 保持当前项目语义 | 按当前位置重新判断 |
| 单行输入、文本编辑器、钉图内可选文字 | I 形 | 选择或编辑文字时保持 I 形 | 按当前位置重新判断 |
| 参数滑块 | 张开手型 | 左键按住时为闭合手型 | 释放、隐藏或禁用时清理抓取状态 |
| 截图选区、绘制工具、尺子定位 | 十字 | 保持精确定位光标 | 切换工具后更新 |
| 选择工具下的画布空白 | 箭头 | 框选期间显示统一十字 | 释放后按当前位置重新判断 |
| 截图选区边缘、标注控制点 | 对应方向的缩放光标，控制点使用四向光标 | 保持操作方向 | 重新命中当前边缘或内容 |
| 可移动选区、标注、钉图、标题栏、工具栏握柄 | 张开手型 | 闭合手型 | 松开后恢复悬停语义 |
| 标注图像中键平移 | 当前工具光标 | 中键按住时为闭合手型 | 中键释放后恢复当前工具，其他按键不结束平移 |
| 滚轮调整工具尺寸 | 当前工具光标 | 固定十字与旁侧尺寸提示，较大尺寸显示实际轮廓 | 900 毫秒后自动恢复，无需移动鼠标 |
| 滚轮缩放标注图像 | 当前工具光标 | 显示比例提示并保留光标 | 提示自动消失 |
| OCR 原图页面 | 箭头 | 无拖动操作 | 保持箭头 |
| 滚动截图区域握柄、可拖动概览 | 张开手型 | 闭合手型 | 释放或失去抓取后恢复 |
| OCR、扫码、上传、钉图翻译 | 当前任务窗口显示忙碌光标 | 可交互控件保留自身光标 | 成功、失败、取消或超时后恢复 |

截图和标注优先保留正在执行的抓取或缩放方向。指针进入工具栏、输入框等控件后，使用该控件的光标。软件指针和画笔预览接管显示期间才隐藏系统指针。

十字图案采用浅色细线、深色轮廓和留空中心，截图选区、标注绘制、框选及软件指针共用同一绘制函数。透明硬件画布保持 64×64，32 位图像行步长为 256 字节，热点与实际操作位置一致。图案和窗口缩放分别处理，避免十字随标注粗细变化。

调整粗细时，十字尺寸保持固定，旁侧提示显示颜色示意和精确数值，并避开窗口边缘及工具面板。线宽、马赛克块和序号气泡直径使用图像像素，文字使用实际字号。选中已有标注时读取该标注的类型、尺寸与颜色。28 至 96 个窗口逻辑像素的尺寸同时显示实际轮廓，马赛克使用方形；小尺寸不叠加轮廓，超过范围时保留数值提示，避免遮挡画面或用缩小轮廓误报尺寸。

标注画布在输入事件处理完成后统一刷新光标，覆盖工具内部提前返回的分支。悬停命中只计算光标，不改写实际拖动状态。单个标注旋转后，缩放光标根据画面方向选择水平、垂直或对角样式；离开图像且没有进行中的操作时使用箭头。

正常释放会提交当前操作。切换工具、中键接管绘制、窗口隐藏、失去激活或抓取中断会撤去未提交草稿并清理抓取状态；已有标注保留最后有效位置及对应撤销记录。没有按键的移动事件也会结束残留拖动。取消抓取事件延后到下一轮事件循环检查，避免吞掉紧接着到达的正常释放；交互序号阻止旧事件取消新手势。绘制和平移期间，滚轮不会启动工具尺寸预览或图像缩放。

内联文字编辑器优先接收 Escape，避免窗口取消快捷键提前消费按键。提交或取消编辑后，立即恢复当前位置对应的画布光标。

钉图的缩放与文字选择优先于后台翻译状态。原生窗口移动可能由窗口管理器接管鼠标释放事件，因此重新进入窗口或收到没有左键的移动事件时，也会清理移动状态。

普通窗口交给窗口管理器移动或缩放时，实际光标遵循桌面的规则。应用在重新获得指针后恢复悬停光标；浮层窗口由应用维护抓取和缩放光标。

标准控件的规则集中在 `src/ui/interaction_cursor.cpp`；截图、钉图、OCR 标题栏和滚动截图分别维护自身操作状态。截图任务通过作用域恢复忙碌状态，包含提前返回和嵌套调用。

控件、实际标注窗口及十字绘制回归检查：

```sh
QT_QPA_PLATFORM=offscreen ctest --test-dir build \
  -R '^(interaction-cursor|annotation-cursor|capture-cross-cursor)$' --output-on-failure
```

`annotation-cursor` 复用应用编译对象，通过真实窗口、工具按钮和 Qt 输入事件验证绘制边界、框选、八方向缩放、旋转、线段控制点、删除按钮、工具栏、文字编辑、预览超时与抓取中断。测试配置目录独立于用户配置。`capture-cross-cursor` 验证硬件缓冲区对齐和系统、软件图案的像素一致性。

实际桌面检查应覆盖：选区建立与调整、标注移动与控制点缩放、文字编辑、工具栏移动、钉图移动与边缘缩放、OCR 页面切换与标题栏移动、录制选项、滚动截图概览，以及设置字段的启用和禁用状态。
